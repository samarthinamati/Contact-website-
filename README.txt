PUJARIGO CONTACT WEBSITE

Files included:
- index.html: Contact Us website with About, Services, FAQ, contact details and a Privacy Policy link.
- privacy-policy.html: Privacy Policy page.
- styles.css: Shared responsive design.

DEPLOYMENT:
1. Download and extract this ZIP.
2. Upload the three files (index.html, privacy-policy.html, styles.css) to the ROOT folder of the GitHub repository connected to Render.
3. If GitHub asks, replace the old index.html and add the two new files.
4. Commit the changes and wait for the Render deploy to finish.
5. Test:
   https://YOUR-WEBSITE-DOMAIN/
   https://YOUR-WEBSITE-DOMAIN/privacy-policy.html

CONTACT FORM:
The form uses FormSubmit at samarthinamati@gmail.com. FormSubmit may require email activation the first time a message is submitted. If you do not want this form service, remove the form or replace it with another provider.
